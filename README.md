# WinMigrationCleaner

**硬件迁移残留清理工具 / Windows Hardware-Migration Leftover Cleaner**

[![.NET](https://img.shields.io/badge/.NET-9.0_WPF-6C7BFF)](https://dotnet.microsoft.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-2BC98A)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows_10/11-0078D4)]()

把 Windows 系统从一台电脑迁移到另一台（换主板、换机装老系统、笔记本换台式机）之后，
旧硬件会在系统里留下三类残留。本工具将它们的检测与清理整合到一个图形界面里，并内置多层安全保护。

```
你的旧电脑：联想笔记本 (Ryzen 7 5800H + RTX 3070 Laptop)
        │  系统盘直接迁移 / 克隆
        ▼
你的新电脑：Intel 台式机 (Ultra 5 + RTX 4060)
        └── 残留：296 个幽灵设备 · 5 个厂商服务 · 23 个过期驱动包 → 一键检测，逐项清理
```

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🔍 **仪表盘** | 一键全面扫描，卡片式展示三类残留数量与本机硬件信息 |
| ▣ **幽灵设备** | 列出所有"已断开连接"的硬件记录（Present=false），勾选批量移除 |
| ⚙ **系统服务** | 按厂商关键字识别旧硬件遗留服务（联想/Tobii/AMD/RST…），支持禁用与删除 |
| ⛁ **驱动包** | 扫描 DriverStore 中未被在线设备引用的驱动包，智能分级：`可清理` / `软件` / `保留` |
| 📄 **导出报告** | 一键导出完整扫描报告到桌面（txt） |

### 人机交互设计（v1.1 重写）

- **启动即扫描**：打开软件自动开始全面扫描，无需手动点击
- **结果本地缓存**：上次扫描结果 7 天内有效，下次启动秒开；F5 随时刷新
- **一键清理安全项**：仪表盘汇总幽灵设备 + 可清理驱动包，一次确认全部完成
- **幽灵设备默认勾选**：扫描完成后可直接点击「移除所选」
- **实时搜索过滤**：每个列表页内置搜索框（Ctrl+F 聚焦），按名称/类别/ID 即时过滤
- **选中即计数**：操作按钮实时显示已选数量（如「移除所选（12）」），未选中时自动禁用
- **点击列头排序**：所有列表支持升序/降序切换，默认幽灵设备/可清理项排前
- **键盘快捷键**：F5 重新扫描 · Ctrl+A 全选/取消 · Ctrl+F 搜索
- **导航计数徽章**：侧边栏实时显示各类残留数量
- **每次点击都有反馈**：导航切换、扫描、清理全部写入活动日志（带时间戳与颜色分级，可折叠）
- **状态栏实时更新**：后台任务逐项显示当前处理对象，永不"假死"
- **危险操作双重确认**：删除前列出完整清单，写明可逆性与后果
- **可随时停止**：长时间批量操作提供「停止」按钮，随时中断
- **权限自适应**：未提权时可完整扫描，点击清理时引导一键提权重启

### 安全设计（核心卖点）

1. **驱动包智能分级**——绝不自动删除：
   - `可清理`：无在线设备引用、非当前平台套件、非已知软件 → 才允许勾选
   - `软件`：属于已安装软件（Npcap / VMware / 远程工具 / 打印机…），默认排除
   - `保留`：当前平台核心组件（显卡/无线/蓝牙套件、Intel IPF 等）
2. **只移除 Present=false 的设备记录**——工作中的硬件永远不会出现在列表里
3. **幂等可重复**——重复运行安全，重新插入的设备会被 Windows 自动重新识别
4. **零第三方二进制**——仅使用 Windows 内置 WMI 与 pnputil
5. **失败透明**——被系统拒绝的项逐条记录（例如当前平台受保护组件），不静默吞错

## 📦 下载与使用

### 方式一：直接运行（推荐）

从 [Releases](../../releases) 下载 `WinMigrationCleaner.exe`（自包含单文件，约 120 MB，无需安装 .NET）。

1. 双击运行（未提权也可扫描）
2. 点击「开始全面扫描」
3. 按需进入各页签，勾选后清理（会请求管理员权限）

### 方式二：从源码构建

以下命令在 **CMD 和 PowerShell 中均可直接执行**（单行，无注释）：

```bat
git clone https://github.com/Jacklady/WinMigrationCleaner.git
cd WinMigrationCleaner\src
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ..\dist
```

构建完成后，成品位于 `WinMigrationCleaner\dist\WinMigrationCleaner.exe`。

> 说明：日常使用无需自己构建，直接到 [Releases](../../releases) 下载 exe 即可。

要求：Windows 10/11 + [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)（仅构建需要）。

## ❓ FAQ

**Q: 移除幽灵设备安全吗？**
安全。列表里只有系统标记为"未在场"的记录；重新插入硬件，Windows 会自动重新识别并安装驱动。
个别手动配置过 COM 口号的设备需要重新设置。

**Q: 为什么"软件"类驱动包不让删？**
Npcap、VMware、远程控制工具等软件的驱动包在软件未运行时同样"未被引用"，
按引用关系判断会被误伤。本工具宁可保守。

**Q: 和 DriverStore Explorer (RAPR) 什么关系？**
RAPR 管理驱动包本体；本工具聚焦"整机迁移"场景，把幽灵设备 + 厂商服务 + 驱动包三件套
串成一条带安全护栏的流程，两者互补，可配合使用。

**Q: 清理后需要重启吗？**
建议重启一次，让 PnP 数据库变更完全生效。
