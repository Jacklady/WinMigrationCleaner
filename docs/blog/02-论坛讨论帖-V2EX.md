# [分享] 整机迁移系统后遗留的 296 个幽灵设备，我写了个工具一键清了

各位好，分享一个自己写的小工具，求轻喷、求反馈。

**背景**：把系统盘从旧笔记本直接迁到新台式机（不重装系统）之后，系统里会留下一大堆旧硬件的尸体：

- 设备管理器「显示隐藏的设备」里几百个灰色幽灵设备（Present=false 的记录）；
- 旧机器厂商（联想/Tobii/AMD RST 之类）的服务还在后台跑；
- DriverStore 里一堆没人引用的过期驱动包。

手动清太痛苦，市场上又没有顺手的全家桶式工具（RAPR 只管驱动包），就自己写了一个：**WinMigrationCleaner**。

**它能干的事**：

1. 幽灵设备：扫描全部设备，灰色的（已断开硬件的残留记录）默认勾选，一键批量移除；正在用的硬件碰不到；
2. 旧厂商服务：按关键字识别候选，建议先禁用观察再删除，删错也能重装恢复；
3. 过期驱动包：DriverStore 里没被引用的包做三档分级——「可清理 / 软件 / 保留」。Npcap、VMware、打印机这类软件驱动会被识别成「软件」排除掉，宁可保守不误删；
4. 打印机驱动删不掉的经典问题（pnputil 0xE0000205，spooler 占用）也处理了：自动「停 spooler → 删包 → 重启 spooler」。

**安全方面**：所有删除都要二次确认；删除失败会翻译 pnputil 的报错（可一键复制）；只用系统自带的 WMI + pnputil，零第三方二进制；重复运行安全。当然，动手前建议建个还原点，老规矩。
